# 数据与发布说明

本次发布从独立目录整理应用源码，未复制原开发仓库的 Git 历史、运行数据库、历史回答、模型调用日志、私人配置或其他项目的业务数据。

## 随源码提供的材料

- `datasets/` 是合成用例；v1 包含 UniHR 与 Clinical 各 50 条，`natural-v2/` 保留对应的自然表达版本。条数说明测试材料范围，不是用户量或产品成效。
- `fixtures/` 的简历与分数表使用 SYN 编号，没有真实求职者资料。
- `web/public/templates/` 是可编辑的合成题目、回答和连接器模板。
- 测试中的假凭证、示例邮箱和电话号码用于检查脱敏行为，不是业务账号。

早期 Clinical 用例包含冻结的资料 ID 与内容指纹，但不包含医学知识库。真正执行专用用例时需要匹配的独立服务；通用工作台和自动化合同测试不需要该知识库。

## 没有随源码提供的内容

`.local/`、`.env`、数据库、历史执行证据、线上用户材料、账号凭证，以及 UniHR / Clinical 的独立服务与私有知识库均不在仓库内。官网案例快照另行部署，不是本地启动所必需的文件。

Clinical 材料用于工程行为测试，没有完成医生临床有效性验证。使用自己的材料时，应先确认授权与脱敏范围。

## 版本验证与许可

可重复执行的本地检查见[运行指南](local-setup.md#验证)。前端构建、后端测试和共享工作台测试与公开源码一同提供；真实模型和业务系统接入仍依赖使用者自己的配置。
