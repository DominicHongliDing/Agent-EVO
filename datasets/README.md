# 合成测试集

这些文件是平台早期 UniHR / Clinical 合同测试所使用的合成输入及工程预期。所有记录标记 `synthetic: true`，不包含真实病历或招聘者资料。

根目录 v1 的两份文件由自动化测试读取，保留它们是为了复现软件行为。`natural-v2/` 是自然表达变体。Clinical 用例的资料 ID / 哈希对应独立知识库快照，该知识库不随 EVO 提供。

第一次体验推荐使用 [`web/public/templates/`](../web/public/templates/) 的通用会议安排示例。要评测自己的产品，请按实际业务重新确认题目、预期与参考依据。
